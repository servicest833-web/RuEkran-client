# Нумерация RuЭкран

Правило владельца от 23 октября 2026 года:

1. 0.1.0-alpha.1 … 0.1.0-alpha.20.
2. 0.1.0-beta.1 … 0.1.0-beta.20.
3. Стабильный выпуск 0.1.0; в обычном описании — «версия 0.1».

prepare-release.py автоматически переводит alpha.20 в beta.1, а beta.20 — в стабильный выпуск. --reuse сохраняет уже зарезервированную версию. Внутренний build увеличивается при каждом новом выпуске и не сбрасывается при смене канала: обновления сравнивают именно его. Windows numeric сохраняет три компонента базовой версии и глобальный build.

На момент введения правила была опубликована версия 0.1.0-alpha.10. Актуальные номера выпуска и технической сборки хранятся в version.json. Опубликованные неизменяемые EXE предыдущих выпусков не перезаписывать.

Уточнение владельца: пока опубликована alpha.12, следующий публичный выпуск — alpha.13. Тестовые итерации этого ещё не опубликованного выпуска сохраняют alpha.13 и различаются суффиксом Test01/Test02 в имени тестового EXE. Не увеличивать видимую alpha для промежуточных проверок. Внутренний build/numeric может расти независимо; после тестов с внутренними 14/15 выпуск alpha.13 использует счётчик не ниже 15.
