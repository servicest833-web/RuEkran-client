# Изменения RuЭкран

## 0.1.0-alpha.17

- Добавлено автоматическое открытие клавиатуры Android при выборе поля ввода на компьютере.
- Улучшена поддержка экономного качества изображения при подключении с Android.
- Сохранена совместимость с предыдущими клиентами.

## 0.1.0-alpha.14

- Добавлен Android-клиент: один APK для ARM32, ARM64 и x86_64.
- Автоматический выбор реле сравнивает задержку и доступность Томска и Москвы; ручной выбор сохранён.
- В сведениях о подключении показывается фактическое реле без номера порта. Исправлена кодировка подсказки Windows.
- При запуске portable-копии рядом с установленным клиентом предлагается открыть установленную программу или обновить её. Защита системной службы сохранена.
- На сайте добавлены отдельные кнопки скачивания Windows и Android.

## 0.1.0-alpha.13

- Добавлен адаптивный масштаб удалённого рабочего стола: изображение вписывается в окно в обоих направлениях. Ручной режим сохраняется для выбранного компьютера.
- Исправлена первоначальная высота окна подключения.
- Надпись при распаковке portable заменена на «Загрузка…».
- Панель управления сервером обновлена отдельно: смена данных входа, парные сеансы, входящие и исходящие счётчики, страницы списка и график нагрузки RuЭкран.

## 0.1.0-alpha.12

- Настройки рядом с ID открываются шестерёнкой. Длинное меню разбито на короткие разделы; высота ограничена рабочей областью экрана, доступна прокрутка.
- Убраны облачный вход RustDesk, устаревший переключатель обновления и дублирующие пункты. Рабочие настройки разрешений, безопасности и сети сохранены.
- Служебная статистика длительности сеансов включена автоматически, без кнопки на главном экране.
- Политика конфиденциальности сокращена: состав технических данных описан в общем разделе.

## 0.1.0-alpha.11

- Исправлена работа переносного клиента с повышенными окнами Windows 7 и большими разрешениями экрана. Запрос прав появляется при запуске единого файла.
- Добавлена необязательная статистика длительности удалённых сеансов, с отдельным включением пользователем.
- Панель управления получила отдельную иконку, поиск, фильтры по дням, сортировку, карточки устройств и раздельную историю присутствия и сеансов.
- Обновлены политика обработки данных, условия использования и выбор аналитики сайта.

## 0.1.0-alpha.10

- Панель на основном компьютере отправляет подписанную команду смены ID выбранному установленному клиенту. Клиент проверяет подпись, прежний ID, ключ устройства, срок и политику; свободный новый ID подтверждается регистрацией на сервере.
- Предложение установки portable-версии остаётся коротким, без сообщений о правах администратора.

## 0.1.0-alpha.9

- В portable-окне оставлены предложение «Установить RuЭкран» и кнопка «Установить», без сообщений о правах администратора. Автоматический запрос прав при запуске сохранён.

## 0.1.0-alpha.8

- Итоговая сборка обновления из программы: повторная проверка записанного portable EXE перед заменой прежнего файла; проверка пакетов для выпуска отклоняет откат на старую сборку.
- Подсказка portable-режима показывает фактические повышенные права; при их отсутствии доступна кнопка «Запросить права». Блок обновления не перекрывает предложение установки.

## 0.1.0-alpha.7

- Уведомление о новом выпуске в левом нижнем углу и обновление из клиента без браузера: загрузка, проверка подписи и SHA-256, обновление установленной либо portable-версии и перезапуск.
- Проверка нашего канала при запуске и каждые 6 часов. Старые и повреждённые пакеты не устанавливаются автоматически.

## 0.1.0-alpha.6

- После сброса или ошибки защищённого рукопожатия прямого TCP-соединения клиент пробует реле в той же попытке подключения. На реле выполняется штатная проверка ключей и пароля.

## 0.1.0-alpha.5

- При неправильном пароле сразу открывается форма повторного ввода с сообщением об ошибке, без промежуточного вопроса «Повторить вход?».

## 0.1.0-alpha.4

- Выбор светлой и тёмной темы на главном экране с сохранением выбора.
- Управляемая смена числового ID установленной службы через локальное подтверждение администратора.
- Отдельная панель статистики сервера для локальной сети.

## 0.1.0-alpha.3

- Индикаторы доступности компьютеров в плитках и списке: в сети, не в сети, статус неизвестен.
- Фоновая проверка доступности через сервер без открытия удалённых сеансов.
- При ошибке связи статус становится неизвестным; устаревшие ответы не сохраняются бессрочно.

## 0.1.0-alpha.2

- Обновление сохраняет версию RuЭкран в списке установленных приложений Windows.
- Уточнены подготовка среды и расположение папок в инструкции к архиву исходников.
- Повторно проверены упаковщик, содержимое поставки и нумерация сборок.

## 0.1.0-alpha.1

- Первая версия с собственной нумерацией RuЭкран.
- Один portable EXE на основе клиента x86 для 32-битной Windows и запуска на x64 через WOW64.
- Запрос повышения прав при обычном запуске неустановленного клиента через штатный механизм RustDesk.
- Возможность установки через встроенный установщик RustDesk.
- Название, значок, логотип и слоган RuЭкран; указание RustDesk в сведениях о программе.
- Лицензионные уведомления и архив соответствующих исходников в пакете.
- Сохранены серверные настройки и техническая версия протокола RustDesk 1.5.0.

Windows 7 SP1 x86/x64 требует проверки запуска на этих системах.
Перечень изменений не заменяет протокол выполненных проверок в диагностическом отчёте.
